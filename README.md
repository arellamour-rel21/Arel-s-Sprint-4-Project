# Arel-s-Sprint-4-Project
This repository is made to take a deeper look into vehicle sales data and turn interesting data into visuals for the public to see the insights
First I started by loading the csv file into VS Code and cleaning the data. That required importing the pandas, scipy, and plotly libraries as well as using methods such as fillna(), astype(), to_datetime()
I created three visuals, 1 histogram, and 2 scatterplots using plotly
In order to launch my project locally, create an enviroment in command and install packages located in the requirements.txt file located in this repository
To run the app, copy the contents in the app.py file also located in this repository. This contains a simulation ran to test and interact with the data visualizations using streamlit, plotly, and pandas. I ctreate a header with st.header and a checkbox that alters the behaviors of the code being ran

# Arel-s-Sprint-4-Project
This repository comtains files the pertain to the analysis and visualization of "Car Sales Advertisement Data" 
The App will take you to a visual representation of a relationship between different models of vehicles, their manufactured years, price, and mileage (odometer reading)
Libraries Imported:
- Pandas - for Data loading and basic cleaning
- PyPlot - For basic visualization
- Streamlit - Further sharing and advanced data visualizations
To access my code locally, you use "streamlit run app.py" my file ('app.py') is listed in my repository
